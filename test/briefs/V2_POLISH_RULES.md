# v2 윤문·칸 맞춤 규칙 (시즌별 다듬기 에이전트용)

목표 두 가지: ① 극장 안 모든 글(제목·부제·요약·자막·무대 글자·만져 보기 설명·학생에게 한 문장·팁·오해·대본)에서 **번역투와 AI 말투를 걷어내** 옆자리 동료 교사가 말하듯 자연스러운 한국어로 ② **글자가 칸 밖으로 밀리는 곳**을 고치기.

## 읽을 것
- `test/briefs/HUMANIZE_QUICK_RULES.md` (AI 티 패턴 룰북) — 먼저 읽기
- 담당 시즌 8편: `episodes/v2/{slug}.js`
- 칸 밀림 보고: `test/overflow-all.log`에서 담당 편 줄 (`[child]` 상자 안 글자가 상자 밖으로, `[scroll]`/`[spill]` 요소가 자기 칸보다 큼, `[low]` 무대 아래 한계 넘음)

## 윤문 원칙
- 의미·사실·수치·출처·고유명사·HTML 태그(`<em>`, `<b>`)는 그대로. 문장 수와 길이는 비슷하게(자막 1개는 2문장 이하, 자막이 길어지면 자막 줄이 늘어 겹침이 생김).
- 번역투 예: "두 겹이에요"(→ "두 가지예요"), "~에 있어서", "~에 대해/대한", "~을 통해", "~함으로써", "~중 하나예요", "~을 가지고 있어요", "~라고 할 수 있어요", "~하는 것이 중요해요", "~의 경우", "~적인", 영어식 소유격 "AI의 답변의", 피동 남발("~되어집니다"), "존재해요/제공해요/경험할 수 있어요".
- AI 말투 예: "A가 아니라 B예요"(둘 다 실제 주장일 때만 남기고, 아니면 B만), 한 줄 극적 마무리("그게 전부예요", "기억하세요"), 억지 3항 나열, "핵심은 ~", "정리하면" 남발, "~라는 점이에요", "~죠?" 되묻기 남발, 과장("놀랍게도", "강력한", "혁신적인"), "함께 알아봐요/살펴볼게요" 같은 진행자 상투구.
- 해요체, 담백하고 구체적으로. 사투리 어미·이모지 금지. "도구마다/서비스마다 달라요" 회피 문장 금지.
- 바꿀 필요 없는 자연스러운 문장은 손대지 않기(과윤문 금지).

## 칸 맞춤 원칙
- 보고된 줄마다 원인을 보고: 글자가 길어서(→ 문구를 줄이거나 size 낮춤), 상자 h가 작아서(→ h 키우되 다른 요소와 겹치지 않게), 폭이 좁아서(→ w 키우기). 글자 크기를 줄이는 건 마지막 수단(최소 size 20).
- 무대 1280×720, 요소는 y 660 이하. 쿼카와 글자 겹치지 않게.
- 고친 뒤 반드시 `node test/overflow.mjs {slug}`와 `node test/overlap.mjs {slug}`가 total 0, `SLUGS={slug} node test/run.mjs` 전부 ✓ 인지 확인. 3px 안팎의 미세 보고도 전부 없애기.

## 작업 방식
- 파일은 Read 후 Edit으로 부분 수정(전체 파일 재작성 금지).
- 담당 8편 외 파일·engine·test 스크립트·registry·palette 수정 금지.
- 끝나면 보고: 편별 바꾼 문장 수, 칸 맞춤 고친 곳, 세 검사 결과, 제목(title)이 바뀐 편 목록(썸네일·자막 다시 뽑아야 해서).
