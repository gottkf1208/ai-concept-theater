- body: 학생이 AI에게 고민을 털어놓은 대화를 보여 주면, 대답의 옳고 그름을 따지기 전에 "AI가 너한테 무엇을 물어봤니?"부터 같이 봐 주세요. 이 벤치마크도 맥락 묻기를 핵심 행동으로 채점해요. 위기 신호가 보이면 학교 위기관리 절차대로 상담교사에게 바로 연결해요.

## 64 `t7-open-weight-jailbreak` — 공개 모델의 안전장치가 쉽게 풀리는 이유

- 부제: 오픈 웨이트의 안전장치, 탈옥·미세조정 우회, 이중 용도
- summary: 가중치를 공개한 모델은 내려받은 사람이 모델 속까지 손댈 수 있어요. 9월 29일 공개된 분석에서 한 공개 모델은 거짓 상황 설정, 생각 미리 채우기, 거절 방향 지우기로 안전장치가 64~100% 풀렸어요. 안전장치가 모델 안과 밖 어디에 있는지, 왜 공개 모델에서는 바깥 겹이 사라지는지, 같은 능력이 방어에도 쓰이는 이중 용도까지 짚어요.
- keywords: 오픈 웨이트, 안전장치, 거절, 탈옥, 프리필, 생각 토큰, abliteration, 거절 방향, 미세조정, 이중 용도, 사이버 보안, 레드팀, CAISI

### 확인된 사실 목록
1. Anthropic Frontier Red Team(2026-09-29, "GLM-5.3 and the spread of advanced cyber capabilities", Fasano·Fleischer·McFaul·Xiao·Gallagher): Zhipu AI(중국 밖 이름 Z.ai)의 오픈 웨이트 모델 GLM-5.3은 사이버 익스플로잇을 끝까지 스스로 만드는 강한 능력이 있는데, 시뮬레이션 시험에서 간단한 기법으로 안전장치가 **64~100%** 우회됐어요. 같은 공격은 안전장치를 갖춘 Claude 모델에서는 성공하지 않았다고 보고. — https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities
2. 같은 글, 수치의 뜻(명백히 해로운 공격 명령에 응한 비율, 칸당 50표본): 그냥 요청 **0%** → 자율 레드팀 에이전트라고 속이는 **거짓 상황 설정 64%** → 모델이 이미 검토하고 진행하기로 한 것처럼 **생각 토큰을 미리 채우기(프리필) 92%** → **거절 제거본(abliteration) 100%**. 시험은 격리된 샌드박스에서 직접 세운 오프라인 표적만 대상으로 했어요. — 같은 URL

### 만져 보기
- title: 안전장치 겹 쌓기
- 화면: 두 열 "닫힌 모델(API)" / "오픈 웨이트(내 컴퓨터)". 겹 4개 체크박스(고정 순서): "요청 검사(바깥)", "생각 미리 채우기 금지(바깥)", "모델 속 거절 훈련(안)", "가중치 비공개(바닥)". 오픈 웨이트 열에서는 바깥 겹·가중치 비공개가 **비활성(disabled)**이고 "내려받은 사람이 직접 운영해요" 설명.
- 조작:
  - select "우회 방법": 거짓 상황 설정 / 생각 미리 채우기 / 거절 방향 지우기 / 소량 미세조정.
  - primary 버튼 "우회 시도": 고정 규칙표로 열마다 결과 표시 — 거짓 상황 설정은 "요청 검사"가 켜져 있으면 막힘, 없고 "모델 속 거절"만 있으면 "뚫릴 수 있음"; 생각 미리 채우기는 "생각 미리 채우기 금지"가 막음; 거절 방향 지우기·소량 미세조정은 "가중치 비공개"만 막음(가중치가 있어야 가능). 결과 줄: "○○ 겹에서 막힘 / 통과". 첫 클릭에서 결과 줄이 생겨야 함(DOM 변화).
  - 닫힌 모델 열에서 겹을 하나씩 꺼 보며 어떤 겹이 어떤 우회를 막는지 확인.
- 위험 정보 없음: 우회 방법은 이름만, 프롬프트·절차 없음.
- desc 끝: "어떤 우회가 어느 겹에서 막히는지 원리만 보여 주는 예시예요. 실제 공격 방법은 담지 않았어요."

### teacherLines
- 공개 모델은 안전장치의 <b>마지막 겹까지 내 컴퓨터 안</b>에 있어서, 마음먹으면 지울 수 있어요.
- 같은 능력이 공격에도 방어에도 쓰여요. 그래서 <b>할 수 있는 것과 해도 되는 것</b>을 나눠 생각해야 해요.

### tip
- body: 학교 서버나 노트북에 공개 모델을 깔아 수업에 쓸 계획이라면, 모델의 거절 기능만 믿지 말고 바깥 겹을 따로 만드세요. ① 학생 입력을 거르는 단계 ② 사용 규칙과 시간 제한 ③ 대화 기록 보관. 커뮤니티에 올라온 "수정판" 모델은 거절 기능이 지워졌을 수 있으니 원래 개발사가 올린 모델만 써요.
- extra: 정보 수업에서 "탈옥 문장을 찾아보자"는 활동은 피하고, 이 편의 겹 도식으로 "어느 겹이 무엇을 막는가"를 토론하게 하세요. 방어 관점(어떻게 막을까)으로 질문을 바꾸는 것이 이중 용도 기술을 가르치는 안전한 방법이에요.

### myth
- myth: 공개 모델도 해로운 요청을 거절하도록 훈련돼 있으니 학교에서 그대로 써도 안전하다.
- fact: 공개 모델의 거절은 모델 속 한 겹뿐이고, 가중치를 가진 사람은 그 겹을 낮은 비용으로 지울 수 있어요. 9월 분석에서 거절 제거본은 해로운 요청에 100% 응했고, 출시 며칠 만에 공개됐어요.
