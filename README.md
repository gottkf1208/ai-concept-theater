# 쿼카 AI 개념극장

**선생님을 위한 AI 원리 3분 극장.** AI를 쓰다가 "이거 왜 이래?", "이거 무슨 원리야?" 하는 순간을 3분 안에 풀어 줘요. 설명을 읽는 게 아니라 **보고(코드로 그린 1분 애니메이션), 만져 보고(브라우저 안 시뮬레이션), 바로 쓰는(학생에게 할 한 문장, 업무 팁)** 경험이에요.

- 사이트: https://gottkf1208.github.io/ai-concept-theater/
- 만든 곳: AI융합교육연구회 Q.U.O.K.A(쿼카연구회) · 두목쿼카(김햇살)
- 대상: 교사(학생용이 아니에요). 연수 도입, 연구회 월례회, 출근길 3분

## 디자인

도식은 라이트 글래스(반투명 흰 카드, 부드러운 그림자)이고, 색은 편마다 달라요. 그 편 쿼카 의상에서 뽑은 두 가지 강조색이 `engine/palette.js`에 있고, 무대 배경·상자·화살표·강조어가 모두 그 색을 따라가요. 새 편을 만들면 팔레트에 한 줄 추가하면 돼요(없으면 기본 파랑·주황).

## 캐릭터

쿼카 해설자는 쿼카연구회 오리지널 쿼카를 바탕으로 AI로 생성한 이미지예요(공용 포즈 8종, 편별 의상 24종과 그 의상의 포즈 세트, 첫 화면 히어로). 극장 안 해설자도 그 편 의상을 입어요. 어떤 그림을 어떤 도구로 만들었는지는 [CREDITS.md](CREDITS.md)에 전부 적어 두었어요. 새 포즈를 추가하려면 [IMAGE_PROMPTS.md](IMAGE_PROMPTS.md)를 참고하세요.

## 사용법

- **혼자 3분:** `watch.html?ep=v1-next-token`. 자막은 항상 켜져 있어서 소리 없이 봐요.
- **연수 모드:** `watch.html?ep=v1-next-token&mode=train`. 큰 글씨 슬라이드. 제목 → 애니메이션 → 만져 보기 → 학생에게 이렇게 → 팁·오해 → 출처 순서로 넘어가요.
- **녹화 모드:** `watch.html?ep=v1-next-token&mode=rec`. 조작 버튼을 숨기고 16:9로 재생해요. 클릭하면 3초 카운트다운 뒤 시작, `Space`를 누르면 바로 시작. 화면 녹화(Windows `Win+Alt+R`, macOS `Shift+Cmd+5`)로 영상 파일을 뜨세요.

## 구조

```
index.html            첫 화면: 오늘의 한 토막, 트랙별 목록, 검색, '학생에게 이렇게' 모아 보기
watch.html?ep=slug    시청 화면 (&mode=train 연수, &mode=rec 녹화, &solo=1 이 편만 보기)
engine/theater.js     타임라인 플레이어(재생·멈춤·장면 이동·자막·음성)
engine/parts.js       장면 부품(쿼카, 말풍선, 화살표, 상자, 토큰 칩, 노이즈 캔버스)
engine/palette.js     편별 색 팔레트(그 편 의상에서 뽑은 두 가지 강조색)
engine/registry.js    에피소드 목록
episodes/*.js         한 편 = 파일 하나
episodes/next/*.js    시즌 2 (E7~E12)
episodes/s3/*.js      시즌 3 (E13~E18)
episodes/s4/*.js      시즌 4 (E19~E24)
episodes/s5/*.js      시즌 5 심화 (E25~)
episodes/s777/*.js    시즌 777 (E41~E70, 2026년 9~10월 소식 기반)
assets/char, key      쿼카 포즈·편별 의상 변형·히어로 (assets/manifest.js에 목록)
test/run.mjs          Playwright 자동 검사 / test/links.mjs 출처 링크 검사 / test/subs.mjs 자막 뽑기
subtitles/            70편 자막(srt·txt). 편집 앱 자막 작업용
```

빌드 없는 정적 사이트예요. HTML, CSS, ES 모듈만 쓰고 외부 라이브러리는 Pretendard 글꼴(jsdelivr) 하나예요. 로그인·분석·추적·개인정보 수집이 없어요.
